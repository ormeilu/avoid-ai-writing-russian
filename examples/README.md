# Примеры конфигов стиля

Файлы для параметра `--style`: `register` задаёт регистр (агент применяет указания как написаны), `mechanics` — оформление.

- `vak.json` — диссертация и статьи ВАК: ГОСТ-оформление списков, десятичная запятая, «ёлочки».
- `docs.json` — документация на русском.

Вызов: «почисти `glava1.md` на месте, `--style vak`».
