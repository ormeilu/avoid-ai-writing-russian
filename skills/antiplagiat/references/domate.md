# «Думейт»: отчёт и тепловая карта

Справка к `../SKILL.md`. Открывай её, когда текст пойдёт в «Думейт» (domate.ru, в вузах и журналах через Elpub) или пользователь принёс его отчёт. Сведения о системе собраны из публикаций разработчика к октябрю 2026 года; детектор обновляют несколько раз в год, так что пороги и интерфейс могут поменяться.

## Что в отчёте

Показатели отчёта: оригинальность, совпадения, цитирования, самоцитирования и доля ИИ-текста. Отдельные вкладки: маскировки (то же, что «подозрительный документ» в «Антиплагиате»), упоминания иноагентов, анализ библиографии с поиском несуществующих источников.

Доля ИИ-текста считается по тепловой карте. У каждого подсвеченного фрагмента один из трёх уровней:

| Цвет | Уровень в данных отчёта | Что значит | Входит в процент |
|---|---|---|---|
| красный | 3, «высокая» | такие признаки встречаются меньше чем в 1 % человеческих текстов | да |
| оранжевый | 2, «средняя» | меньше чем в 5 % | нет |
| жёлтый | 1, «низкая» | меньше чем в 10 % | нет |

Поэтому отчёт с 0 % ИИ-текста может содержать оранжевые и жёлтые фрагменты. Правь в первую очередь красные: только они двигают процент. Оранжевые и жёлтые разработчик называет зоной внимания, в других системах они могут оказаться красными.

Подсветка идёт границами предложений и часто тянется через несколько абзацев подряд. Проверяющий может отключить фрагмент с комментарием, тогда процент пересчитывается, а в отчёте остаётся история изменений.

Бесплатная проверка (3 в день на сайте, в боте в Telegram и MAX) показывает только оригинальность и долю ИИ. Тепловая карта есть в полном отчёте; осенью 2026 года он стоил 249 ₽. Частные проверки, по словам разработчика, не попадают ни в индекс, ни в поиск дубликатов, так что повторная загрузка своей работы не создаёт самоплагиат.

## Как получить разметку

Нужен документ ровно в той версии, которую загружали, и красные фрагменты. Варианты, от самого надёжного:

1. **Страница отчёта в браузере.** Если у тебя есть браузер с выполнением JavaScript (встроенный браузер, Claude in Chrome и подобные), попроси пользователя открыть отчёт и войти в аккаунт самому. Пароль не вводи. На вкладке «ИИ-текст» выполни скрипт ниже: он возвращает фрагменты тепловой карты в JSON. Сохрани результат в файл, например `heat.json`.
2. **PDF отчёта по ИИ.** Его выгружают со страницы отчёта. Прочитай PDF и выпиши красные фрагменты в текстовый файл, по одному на абзац через пустую строку. Не уверен в цвете — покажи пользователю найденные куски и спроси.
3. **Скриншоты** страниц отчёта с подсветкой: то же, что с PDF.
4. **Только итоговая доля** из бесплатной проверки. По ней подстраивается лишь общая строгость (`calibrate --share`), а какие абзацы править, она не говорит.

Ссылка на отчёт содержит `accessToken`, с ним отчёт откроет любой. Не вставляй такую ссылку в файлы, коммиты и ответы, если пользователь сам об этом не просил.

## Скрипт для страницы отчёта

Скрипт берёт уровни и координаты фрагментов из данных отчёта (`machinegen/…/formatted_layout`), прокручивает документ, чтобы прогрузились все страницы, и собирает слова текстового слоя PDF, попавшие в каждый фрагмент. Это внутренний интерфейс страницы, а не документированный API: проверено в октябре 2026 года. Если скрипт падает или возвращает пустой список, переходи к PDF.

```javascript
const q = new URLSearchParams(location.search);
const id = q.get("documentId"), tok = q.get("accessToken");
const mg = await (await fetch(`/api/v1/report/machinegen/${id}/formatted_layout?accessToken=${encodeURIComponent(tok)}`)).json();
const first = document.querySelector(".pdf-page-wrap");
let box = first.parentElement;
while (box && !(box.scrollHeight > box.clientHeight + 50 && getComputedStyle(box).overflowY !== "visible")) box = box.parentElement;
for (let i = 1; i <= 15; i++) { box.scrollTop = box.scrollHeight * i / 15; await new Promise(r => setTimeout(r, 700)); }
const words = [];
for (const wrap of document.querySelectorAll(".pdf-page-wrap")) {
  const pn = +wrap.getAttribute("data-page-number");
  const page = mg.pages.find(p => p.pageNr === pn);
  const R = (wrap.querySelector("canvas") || wrap).getBoundingClientRect();
  for (const s of wrap.querySelectorAll("span")) {
    if (s.querySelector("span") || !s.textContent.trim()) continue;
    const r = s.getBoundingClientRect();
    const x = (r.left + r.width / 2 - R.left) / R.width, y = (r.top + r.height / 2 - R.top) / R.height;
    let level = 0;
    for (const b of page ? page.blocks : []) for (const z of b.boxes)
      if (x >= z.left - 0.003 && x <= z.left + z.width + 0.003 && y >= z.top - 0.002 && y <= z.top + z.height + 0.002) level = Math.max(level, b.level);
    words.push({ pn, level, t: s.textContent.trim() });
  }
}
const out = [];
for (const w of words) {
  const last = out[out.length - 1];
  if (last && last.level === w.level) { last.words.push(w.t); if (!last.pages.includes(w.pn)) last.pages.push(w.pn); }
  else out.push({ level: w.level, pages: [w.pn], words: [w.t] });
}
JSON.stringify({ share: mg.score, fragments: out.filter(f => f.level > 0).map(f => ({ level: f.level, pages: f.pages, text: f.words.join(" ") })) });
```

`share` — доля ИИ-текста из отчёта (0,38 значит 38 %). Сохрани результат в файл как есть: `calibrate` и `judge score` читают его как разметку и берут только красные фрагменты (`level` 3). Число красных фрагментов в JSON должно совпасть со списком «Высокая» в левой панели отчёта; если не совпадает, часть страниц не прогрузилась, запусти скрипт ещё раз.

## Что делать с разметкой

```bash
uv run --project ../.. aiw-ru calibrate --system domate --doc работа.md --marked heat.json
uv run --project ../.. aiw-ru antiplagiat работа.md --system domate
```

`работа.md` — тот самый загруженный документ, сконвертированный в Markdown. Калибровка «Думейта» хранится в том же `.aiw-ru.json`, что и калибровка «Антиплагиата», но отдельно от неё. Красные фрагменты сопоставляются с абзацами по первым и последним словам, поэтому переносы строк и мелкие расхождения текстового слоя не мешают.

Калибровка по одному-двум отчётам слабая: семь признаков детектора не описывают то, на что смотрит «Думейт», и оценка остаётся грубой. Главная польза разметки в другом: она прямо говорит, какие абзацы править. Порядок правки — в `../SKILL.md`, шаг 3.
