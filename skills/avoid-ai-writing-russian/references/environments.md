# Где запустить детектор без командной строки

Часть скилла, оглавление в `../SKILL.md`. Файл нужен, когда ты работаешь без командной строки (веб-версия чата, мобильное приложение, чат без выполнения кода), а пользователь спрашивает, как получить проверку детектором. Перескажи ему один-два пути, которые подходят его среде, а не весь файл.

Детектору нужен Python 3.12 или новее и пакет `aiw-ru` из PyPI. Необязательные модели скачиваются с huggingface.co; где сеть закрыта, детектор работает без них, только без строки «Вероятность ИИ».

## Свой компьютер

Самый полный вариант: агент сам запускает `scan`, `validate` и модели.

- Claude Code ставит скиллы плагином:

  ```bash
  claude plugin marketplace add ormeilu/avoid-ai-writing-russian
  claude plugin install avoid-ai-writing-russian@avoid-ai-writing-russian
  ```

- Codex, Kimi Code, pi, Hermes и DeepSeek Harness: команды в разделе «Установка» README, https://github.com/ormeilu/avoid-ai-writing-russian.
- Без агента пользователь ставит один детектор и присылает в чат его вывод, а ты разбираешь находки по каталогу:

  ```bash
  pip install aiw-ru
  aiw-ru scan текст.md --context vak
  ```

  После твоей правки целого документа пусть сохранит её в файл и пришлёт ещё вывод `aiw-ru validate текст.md правка.md`: так проверяется, что код, числа и ссылки остались на месте. Вместо `pip` подойдёт `uv tool install aiw-ru`.

## Выполнение кода в самом чате

- Claude (claude.ai, приложения для компьютера и телефона): Settings > Capabilities > Code execution and file creation. На тарифах Free, Pro и Max оно включено по умолчанию вместе с доступом к PyPI и GitHub, в Team и Enterprise его настраивает администратор организации. Huggingface.co в разрешённые адреса по умолчанию не входит, поэтому модели не скачаются.
- ChatGPT: контейнер для кода ставит пакеты через `pip`, но других адресов в интернете не видит. Если запуск кода в разговоре доступен, `aiw-ru` ставится туда; модели не скачаются.

В обоих случаях песочница живёт, пока жив разговор: в новом чате детектор ставят заново.

## Облачный агент

Полная Linux-песочница, текст передают файлом или через репозиторий.

- Claude Code on the web (claude.ai/code): уровень сети Trusted, выбранный по умолчанию, открывает PyPI, и `pip install aiw-ru` работает. Если модели не скачиваются, в настройках сети среды выберите Custom и добавьте huggingface.co.
- Codex в облаке (chatgpt.com/codex): поставьте `aiw-ru` в скрипте установки среды, у него есть доступ в интернет, или разрешите агенту менеджеры пакетов в сетевых настройках среды.

## Терминал через MCP

Если чат умеет подключать свои MCP-коннекторы, командную строку можно дать ему так.

- Remote Desktop Commander: терминал и файлы компьютера пользователя для claude.ai и ChatGPT. На компьютере запускают `npx @wonderwhy-er/desktop-commander@latest remote`, в чате добавляют коннектор `https://mcp.desktopcommander.app/mcp`: в Claude через Settings > Connectors > Add custom connector, в ChatGPT через режим разработчика в Settings > Apps & Connectors. Команды идут через сервер Desktop Commander и выполняются на компьютере пользователя, поэтому ставь что-либо только с его согласия.
- Облачная песочница E2B (`@e2b/mcp-server`) подключается к Claude Desktop и другим клиентам с локальными MCP-серверами. Нужен ключ API E2B; на свой компьютер агент при этом не попадает.
