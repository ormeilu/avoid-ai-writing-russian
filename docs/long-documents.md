# Длинные документы

Трансформеры aiw-ru читают одно окно в 512 токенов, это 300–350 слов. Длинный текст `aiw-ru classify` проверяет по фрагментам: режет его на куски в одно окно по границам предложений, соседние куски заходят друг на друга на четверть окна, и у каждого своя вероятность. Здесь замер двух вещей: находят ли фрагменты ИИ-текст, который занимает только часть документа, и как часто они поднимают ложную тревогу на тексте, который целиком написал человек.

## Документы

Смешанных документов такой длины в LLMTrace почти нет: у смешанных текстов части detection медиана 639 знаков. Поэтому документы собраны из текстов части classification скриптом [`scripts/long_docs.py`](../scripts/long_docs.py). Тексты одного жанра (статьи, новости, рассказы, отзывы, справочные тексты, ответы на вопросы) склеены через пустую строку, ИИ-куски размечены по знакам. Каждый текст попал только в один документ. ИИ-тексты, которые начинаются с начала человеческого текста, отброшены: генератор продолжал чужой текст, и разметка по знакам для них неверна. Среди текстов `create` таких около трети.

Документ склеен из разных текстов одного жанра, поэтому на стыке меняется тема. В настоящем смешанном документе человек пишет начало, а модель продолжает ту же мысль, и найти ИИ-кусок там может быть труднее.

Как читать строки:

- «Человеческий документ: хоть один фрагмент выше порога» — ложная тревога на документе, который целиком написал человек. Именно так выглядит вывод `classify`: «выше порога 1 фрагмент из 12».
- «ИИ-кусок найден» — выше порога хотя бы один фрагмент, в котором ИИ-текста больше половины.
- «Доля ИИ-знаков под отмеченными фрагментами» — сколько ИИ-текста накрыли фрагменты выше порога. «Доля ИИ среди отмеченных знаков» — сколько в них действительно ИИ-текста.
- «По началу» — так было до 2.1.0: одна вероятность по первому окну документа.

## Выводы

Фрагменты находят то, чего не видит начало. В смешанных документах ИИ-кусок нашёлся в 88–94 % случаев против 30–34 % по первому окну, а вставку в конце начало не видит почти никогда (0–1 %). Документ, целиком написанный моделью, все три модели находят всегда.

Цена этого — ложные тревоги на длинном человеческом тексте. У отдельного человеческого фрагмента шанс оказаться выше порога 4–9 %, а фрагментов в документе на 20 тысяч знаков около 11. В итоге хоть один фрагмент выше порога получил каждый четвёртый–третий человеческий документ: 22,5 % у `transformer`, 29,7 % у `modernbert`, 36,9 % у `mini-frida`. По началу документа ложных тревог почти нет, 0–2 %.

Поэтому один фрагмент выше порога в длинном тексте — слабый признак, а не приговор. Два фрагмента и больше встречаются в 8–16 % человеческих документов и в 73–86 % смешанных. Более строгий порог для фрагментов помогает меньше: при 0,98 вместо 0,5 ложные тревоги у `transformer` падают до 11,7 %, у `modernbert` до 16,2 %, а у `mini-frida` почти не меняются (31,5 %), её ошибки на человеческих фрагментах уверенные.

Хуже всего находятся одиночные вставки из одного текста: 69–84 %. Вставка короче фрагмента, и во фрагменте рядом с ней человеческий текст. Из-за того же отмеченные строки шире ИИ-куска: в документах с несколькими вставками ИИ-текст занимает только 42–51 % отмеченного. Фрагмент, где ИИ-текста больше половины, модели отмечают в 66–96 % случаев, где меньше четверти — в 6–21 %.

Перекрытие в четверть окна оставлено. Без перекрытия ИИ находится реже (86,6 % против 89,8 % на valid), перекрытие в половину окна находит чуть больше (92,1 %), но даёт больше ложных тревог (24,8 % против 19,3 %) и почти вдвое дольше.

Из трёх моделей больше всего ИИ-текста находит `modernbert`, меньше всего ложных тревог у `transformer`, он же самый быстрый. У `mini-frida` ложных тревог больше всех.

## Воспроизвести

Нужны части classification test и valid (`scripts/llmtrace.py fetch --split test`, затем `--split valid`) и модели в кэше (`aiw-ru models install modernbert transformer mini-frida`).

```bash
uv run --group train --extra ml scripts/long_docs.py build --split test
```

```bash
uv run --group train --extra ml scripts/long_docs.py eval --split test --model transformer
```

```bash
uv run --group train --extra ml scripts/long_docs.py report --overlaps 0 0.25 0.5 --out docs/long-documents.md
```

Для сравнения перекрытий `build` и `eval` запускаются ещё и с `--split valid` и `--overlap 0`, `0.25`, `0.5`.
