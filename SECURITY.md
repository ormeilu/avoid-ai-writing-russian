# Безопасность

Детектор работает локально, ничего не отправляет в сеть и не хранит тексты. Файл калибровки `.aiw-ru.json` содержит только числовые признаки фрагментов, без самого текста.

Если нашли уязвимость (например, регулярное выражение, которое зависает на специально подобранном тексте), сообщите через [закрытое сообщение об уязвимости](https://github.com/ormeilu/avoid-ai-writing-russian/security/advisories/new), а не открытой задачей.
